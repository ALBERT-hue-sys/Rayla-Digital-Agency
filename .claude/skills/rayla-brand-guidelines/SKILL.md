# Rayla Digital Agency — Brand Guidelines

## Design Direction
- Editorial, Unsplash-inspired look — heavy photo use, tight copy
- Reference agencyjet.com for layout and design tone

## Typography
- Display / headings: `Montserrat` — `var(--font-display)`
- Body copy: `Poppins` — `var(--font-body)`

## Brand Colors
CSS custom properties defined in `css/style.css` (`:root`) — always reference these variables rather than hardcoding hex values.

| Role | Variable | Hex |
|---|---|---|
| Black | `--black` | `#0b0b0a` |
| Near-black | `--near-black` | `#171613` |
| Dark Grey | `--dark-grey` | `#2b2a26` |
| Mid Grey | `--mid-grey` | `#858175` |
| Light Grey | `--light-grey` | `#f1efe9` |
| Off-white | `--off-white` | `#faf9f6` |
| White | `--white` | `#ffffff` |
| Gold (accent) | `--gold` | `#b8923a` |
| Gold, soft | `--gold-soft` | `#d9bb78` |
| Gold, dark | `--gold-dark` | `#8a6a24` |
